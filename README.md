## KPI Basics Challenges
### Finance at Greenweez :

#### Objective:
As analysts, you will build a complete daily profitability report by calculating and comparing different types of margins:
gross, operating and advertising-adjusted.
  - Calculate key finance KPIs and metrics like gross margin and operating margin
  - Cleaning data, using formulas like XLOOKUP and IF, and building pivot tables
  - Build a clear daily report to help the finance team track how profitable Greenweez really is
